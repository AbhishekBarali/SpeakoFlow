Fine control over exactly how transcribed text is inserted into the active app. Most people never need to touch these — the defaults just work.

## Paste method

*Clipboard, Direct, None, External script. Default: Clipboard.*

How transcribed text is inserted. **Clipboard** pastes via `Ctrl/Cmd` + `V`, with `Ctrl+Shift+V` and `Shift+Insert` variants. **Direct** types it key by key. **External script** hands off to a script you point to.

## Typing tool

*Auto, specific tool. Default: Auto (recommended).*

**Linux only.** The tool used for the Direct paste method. Leave on Auto unless you have a reason to change it.

## Clipboard handling

*Don't modify clipboard, Copy to clipboard.*

Whether the transcription stays in your clipboard after pasting. The default restores what you had before.

## Auto submit

*Off, Enter, Cmd+Enter, Super+Enter, Ctrl+Enter. Default: Off.*

Send a key combination automatically after text is inserted. Handy for firing off chat messages hands-free.

## Append trailing space

Add a space after inserted text so consecutive dictations don't run together.

<Tip>
  If text is occasionally cut off or the wrong text pastes, the paste delay and extra recording buffer in [Debug settings](/settings/debug) usually fix it. For a specific app that misbehaves with clipboard paste, try the **Direct** paste method.
</Tip>
