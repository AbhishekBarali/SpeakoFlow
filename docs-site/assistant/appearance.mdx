Make the floating panel fit your desktop. A live preview shows your changes as you make them.

## Text size

*Small, Medium, Large.*

Size of the chat text in the assistant panel.

## Panel size

*Small, Compact, Standard, Large.*

Overall size of the floating panel. You can also drag its edges to resize.

## Panel opacity

How opaque the floating panel is. 100% is fully solid; lower values let the desktop blur through.

<Note>
  App-wide theme and text size live in [General settings](/settings/general). These three only affect the floating panel.
</Note>
