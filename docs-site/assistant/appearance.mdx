Make the floating panel fit your desktop, in *Settings → Assistant → Panel appearance*. A live preview shows your text size and opacity as you change them.

## Text size

*Small, Medium, Large. Default: Medium.*

Size of the chat text in the assistant panel.

## Panel size

*Small, Compact, Standard, Large. Default: Standard.*

Overall size of the expanded floating panel. You can also drag its edges to resize; a manual resize wins for the rest of the session, and the next app start goes back to the preset.

Whichever size you pick is clamped to the monitor the panel is on, so a large preset shrinks to fit a small display instead of running off the edge or hiding under the taskbar.

## Panel opacity

*Range 50%–100%. Default: 100%.*

How opaque the floating panel is. 100% is fully solid; lower values let the desktop show through, which helps when you're reading an answer against the thing you asked about.

<Note>
  The panel is dark-only. There is no accent color or light/dark option for it — those were removed, so these three settings are the whole surface. App-wide theme and text size for the settings window live in [General settings](/settings/general).
</Note>
