The assistant runs on whatever model you choose. This is the single most important assistant setting — set it in *Settings → Assistant → Assistant brain*.

## Choosing a local model

The catalog recommends three conversation-first choices: quickest, recommended, and more capable but slower. SpeakoFlow detects your GPU and reports graphics memory so you can gauge which size will run well.

| Tier | Example | Notes |
| --- | --- | --- |
| Small / quick | Gemma 4 E2B, Gemma 3 1B | Runs on any machine. Great for tidying writing and simple questions. |
| Recommended | Gemma 4 E4B | A strong balance of quality and speed for conversation. |
| More capable | Gemma 4 12B, Qwen vision models | Sharper answers, some can see your screen — but slower, best with a strong GPU. |

<Note>
  Vision-capable models download an extra image file automatically so they can read your screen. You can also browse Hugging Face for other GGUF models — see [Custom models](/models/custom-models).
</Note>
