Optional. When a question needs current, factual information, the assistant can look it up. The model decides when to search — you don't have to ask.

Enable it in *Settings → Assistant → Web search*. Off until you turn it on.

## Allow web search

*Default: off.*

Let the assistant search the web when a question needs current information.

## How it decides to search

The model itself decides, by calling a `web_search` tool while it writes its reply. There's no keyword check and no separate planner to configure — if the question needs fresh facts, it searches; if it doesn't, it just answers.

Each search is a single round-trip that returns titles and snippets. Result pages are never fetched, so a search costs about a second, not a browsing delay. If a search fails or is slow, the assistant answers without web context rather than leaving you waiting.

## Two ways to search

### Use OpenRouter's built-in search

*Default: off.*

If you use OpenRouter, turn this on to let OpenRouter run the search itself (its `:online` mode) using your OpenRouter credits — **no separate search API key needed**. When off, the app searches with your own search provider below.

### Search provider

*Serper, Brave, Tavily, Exa, SerpAPI, TinyFish. Default: Serper.*

All six return titles and snippets, and each needs one API key. Every one has a free tier.

| Provider | What you get |
| --- | --- |
| **Serper** | Google results, fast. The default. |
| **Brave Search** | An independent index. |
| **Tavily** | LLM-optimized; returns a synthesized answer. |
| **Exa** | Neural, semantic search. |
| **SerpAPI** | Google SERP. |
| **TinyFish** | Its own index, built for agents. Free with no credit card, 30 queries a minute, sub-second latency. |

<Tip>
  Serper stays the default. TinyFish is the most generous free tier of the six — no card required — if you'd rather not hand over payment details to try search out.
</Tip>

### API key

Key for the selected search provider. Not needed when using OpenRouter's built-in search.

## Quality controls

### Sources to use

*1–10.*

How many results to read.

### Search depth

*Quick, Standard, Deep.*

**Quick** for simple facts, **Standard** for most questions, **Deep** for hard ones.

### Test search

Run a sample search with the current provider and key to confirm it's working before you rely on it.
