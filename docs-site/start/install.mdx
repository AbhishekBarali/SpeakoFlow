---
title: "Install SpeakoFlow"
description: "Download and install SpeakoFlow on Windows, macOS, or Linux, including the one-time Terminal command that clears the macOS \"app is damaged\" message on unsigned builds."
icon: "download"
---

Download SpeakoFlow for your operating system from the [Releases page](https://github.com/AbhishekBarali/SpeakoFlow/releases).

| Platform | Files |
| --- | --- |
| **Windows** | `.exe` installer and `.msi`, x86_64 |
| **macOS** | `.dmg`, Apple Silicon |
| **Linux** | AppImage and `.deb`, each in x86_64 and ARM64 |

<Tip>
  The download buttons on [speakoflow.com](https://www.speakoflow.com) pick the right file for the machine you're on. Reading this from a different computer than the one you're installing on? Add `?os=mac`, `?os=linux`, or `?os=linux&arch=arm64` to the homepage URL to get that platform's download instead.
</Tip>

<Tabs>
  <Tab title="Windows">
    Download the `.exe` installer and run it, or the `.msi` if you deploy with one.

    <Note>
      Windows code signing isn't in place yet, so SmartScreen may warn you the first time you run the installer.
    </Note>
  </Tab>

  <Tab title="macOS">
    SpeakoFlow works fully on macOS, but it isn't signed by Apple yet, so macOS blocks it on first launch with a message that says *"SpeakoFlow is damaged and can't be opened."*

    <Warning>
      **The app is not damaged.** That wording is what macOS shows for any app it can't trace to a paid Apple Developer account. Signing costs $99/year, which this project doesn't have yet, so the block is expected and harmless. Sorry for the extra step.
    </Warning>

    <Steps>
      <Step title="Drag SpeakoFlow into your Applications folder">
        Open the `.dmg` and drag the app across, as usual.
      </Step>

      <Step title="Clear the quarantine flag">
        Open Terminal (press `Cmd` + `Space`, type *Terminal*) and run:

        ```bash
        xattr -dr com.apple.quarantine /Applications/SpeakoFlow.app
        ```
      </Step>

      <Step title="Open it normally">
        From Launchpad, Spotlight, or Applications.
      </Step>
    </Steps>

    You only do this once per version you install. The command removes the "downloaded from the internet" tag macOS puts on the file. Because SpeakoFlow can't auto-update while unsigned, you'll repeat it next time you download a new version — one command per update, never per launch.

    There's no button to click instead: macOS 15 and later removed the old right-click → *Open* bypass, and "damaged" is the one case where no *Open Anyway* button appears in *System Settings → Privacy & Security*. Apple code signing and notarization is on the roadmap and removes this step entirely.

    <Note>
      Builds are Apple Silicon only. GitHub retired its Intel build machines in December 2025, so there's no way to produce and test an Intel build right now.
    </Note>
  </Tab>

  <Tab title="Linux">
    **Arch and derivatives** — install from the AUR:

    <CodeGroup>
      ```bash yay
      yay -S speakoflow-bin
      ```

      ```bash paru
      paru -S speakoflow-bin
      ```
    </CodeGroup>

    **Ubuntu 24.04+, Mint 22+, Pop!\_OS, Tuxedo OS, Debian 13** — the `.deb`:

    ```bash
    sudo apt install ./SpeakoFlow_*_amd64.deb
    ```

    **Everything else, including Fedora and openSUSE** — the AppImage. Make it executable and run it:

    ```bash
    chmod +x SpeakoFlow_*.AppImage
    ./SpeakoFlow_*.AppImage
    ```

    <Note>
      **Two things worth knowing.** The `.deb` is built on Ubuntu 24.04 and needs that era of glibc — on Ubuntu 22.04 or Debian 12, use the AppImage. And there's no `.rpm`: its packaging doesn't yet bundle the speech engine, and an `.rpm` that installs but can't transcribe is worse than none.
    </Note>

    The AppImage can't register its own icon or app-menu entry — that's normal AppImage behaviour, not a SpeakoFlow bug, and it's why the `.deb` is the better choice where there is one. The icon appears once the app is running; the file in your file manager stays generic. A helper like Gear Lever or AppImageLauncher adds a menu entry if you want one.
  </Tab>
</Tabs>
