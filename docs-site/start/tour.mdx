SpeakoFlow has a sidebar of pages for the things you do, a Settings dialog for preferences, and a tray icon that stays out of the way.

## Sidebar pages

The sidebar is on the left of the main window. Pages are listed in this order:

| Page           | What it is for                                                                                                                                                          |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Home**       | Your shortcuts (with a Hold to talk / Tap to toggle switch), the models doing each job, and recent dictations.                                                          |
| **History**    | Every dictation, question, and conversation. Play recordings back, recover dismissed ones, or continue a chat. See [History](/personalize/history).                     |
| **Assistant**  | The assistant's model, voice, screen vision, web search, and conversation settings. See [The quick ask](/assistant/panel) and [Conversations](/assistant/conversation). |
| **Meetings**   | Start and stop meeting recordings, pick a note template, and review past meetings. See [Recording a meeting](/meetings/recording).                                      |
| **AI cleanup** | Turn it on, pick the cleanup model and writing style, and see a before-and-after example. See [AI cleanup](/writing/ai-cleanup).                                        |
| **Dictionary** | Add names and jargon so they are transcribed correctly, and set up text replacements. See [Custom words](/dictation/custom-words).                                      |
| **Insights**   | Words dictated, speaking speed, time saved, number of dictations, and a six-month activity map. See [Insights](/personalize/insights).                                  |

Below a dividing line:

| Page       | What it is for                                                                                                                                                                               |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Models** | Everything that runs a job (speech to text, assistant, cleanup, voice), organised by job. Download, remove, or import models here. See [Transcription models](/models/transcription-models). |

At the bottom of the sidebar, the speech model currently in use is shown with a status dot (ready, loading, error, or cloud).

## Settings

Click the gear icon at the bottom of the sidebar to open the Settings dialog. It has these tabs:

| Tab                | What it covers                                                                                                |
| ------------------ | ------------------------------------------------------------------------------------------------------------- |
| **General**        | Appearance, text size, app language, startup behavior, and the replay-onboarding button.                      |
| **Shortcuts**      | Every keyboard shortcut and the Hold to talk / Tap to toggle switch.                                          |
| **Audio**          | Microphone, output device, feedback sounds, and their volume.                                                 |
| **Dictation**      | The recording overlay style, paste method, clipboard handling, trailing space, auto-submit, and spoken emoji. |
| **Privacy & data** | Recording retention (how long recordings are kept) and the app data and log folders.                          |
| **Advanced**       | Model unload timeout and experimental features.                                                               |
| **About**          | Version, update check, links, and the license.                                                                |
| **Debug**          | Only visible after enabling debug mode. Log level, keyboard engine, acceleration, and diagnostic settings.    |

Features like AI cleanup, the assistant, and the dictionary are configured on their own sidebar pages, not in Settings.

## Feedback

The **?** button beside the gear icon opens the feedback dialog. It sends your message (and optional email and screenshots) to the maintainer. Nothing else is sent unless you tick the system info box. See [About](/reference/about) for more on how feedback works.

## System tray

SpeakoFlow sits in your system tray. Right-click the icon for quick actions: show the window, send feedback, or quit. Closing the main window hides it to the tray rather than quitting, unless you turn on "Quit when the window is closed" in _Settings → General_.
