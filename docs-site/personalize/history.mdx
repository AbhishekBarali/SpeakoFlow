Your recent dictations, Flow generations, and assistant chats — stored on this device, and yours to reuse or delete.

Find it in the *History* section. One feed, newest activity first, filtered by **All**, **Dictations**, **Flow**, or **Assistant chats**.

## What each row shows

- **Dictations** — the transcription. If it was cleaned with AI, the row shows both: *Original transcription* on top and *Final text* below it, so you can see exactly what cleanup changed.
- **Flow** — *You said* (the spoken command as transcribed) and *Flow output* (the exact text that was pasted). A generation that failed or was cancelled still appears, marked as having produced no output.
- **Assistant chats** — one row per conversation, labeled with a title taken from your first message. Expand it to read the whole thing rendered as it appeared in the panel.

Messages that carried an image keep a small thumbnail inline — screen captures get a camera badge — and clicking one opens it full size. Only the compact thumbnail is stored; the full-resolution frame was sent to the model and never persisted.

## What you can do

Each dictation and Flow row carries a player, so you can hear the original audio. The rest of the actions appear when you hover over a row.

- **Copy** the transcription, the Flow output, the cleaned final text, or a whole conversation.
- **Star** a dictation or Flow recording to keep it — starred recordings are never auto-deleted.
- **Re-transcribe** a recording with your current model, e.g. after switching to a more accurate one. The row updates in place.
- **Continue** an assistant chat right where it left off; it reopens in the panel and keeps saving to the same row.
- **Delete** individual entries, or open the recordings folder on disk.

Assistant chats can be copied, continued, and deleted, but not starred or re-transcribed — there is no audio behind them.

## Recording storage

The storage controls sit above the feed, since a long history scrolls far enough to bury anything below it.

<Note>
  These controls affect **dictation and Flow recordings only**. Assistant chats have separate storage and are never counted or auto-deleted by these rules.
</Note>

### Auto-delete recordings

*Never, **Keep a set number** (default), After 3 days, After 2 weeks, After 3 months.*

How unstarred recordings are cleaned up. "Never" keeps everything forever. The policy is re-applied every time a new recording is saved, not just at startup, so the list always matches what you asked for. Changes apply immediately.

### Recording limit

*Default: 20.*

The maximum number of unstarred dictation and Flow recordings to keep. This row only appears when *Auto-delete recordings* is set to "Keep a set number". Starred recordings are always kept and don't count toward the limit.

Deleting an entry removes its audio file too — unless an older entry still points at the same file, in which case the file survives until the last reference is gone.
