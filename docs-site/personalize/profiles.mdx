A profile is a persona for the assistant. It sets the name, the role, the instructions behind it, how long replies run, and an optional greeting.

Switch profiles from the panel header at any time. Manage them on the **Assistant** page under the personal section. Clicking _Manage_ opens the profiles editor.

## Built-in profiles

| Profile        | What it is for                                             | Reply length        |
| -------------- | ---------------------------------------------------------- | ------------------- |
| **Assistant**  | Balanced, general-purpose help.                            | Your global setting |
| **Companion**  | Warm, empathetic support for talking something through.    | Medium              |
| **Quick**      | Fast and to the point, usually one or two sentences.       | Short               |
| **Unfiltered** | Blunt, honest feedback.                                    | Your global setting |
| **Cat**        | A joke profile. Replies with meows. Does not call a model. | Fixed               |

All five are editable and can be duplicated. Only **Assistant** cannot be deleted, because the assistant always needs a base persona to fall back to. Cat never gets [screen vision](/assistant/screen-vision), regardless of your switches.

Edited a built-in and want it back? **Restore default** resets that one profile to the version shipped with the app. Deleted one? **Restore built-ins** in the menu re-adds anything missing and leaves your own profiles alone.

## Creating a profile

Start from scratch, duplicate an existing one, or use **Create with AI**.

With **Create with AI**, you describe the persona you want, like "a concise release-notes writer" or "a patient tutor who explains every step", and SpeakoFlow drafts its name, instructions, and greeting. You can dictate the description straight into the box with the mic button.

## What a profile contains

| Field               | Notes                                                                                                                               |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| **Name**            | Shown in the list and in the panel header.                                                                                          |
| **Role**            | A subtitle for your own benefit. Never reaches the model.                                                                           |
| **Avatar**          | Optional image upload. Built-ins get a designed icon. Your own profiles get their initial on a color derived from the profile's id. |
| **Instructions**    | The system prompt that shapes the personality. Replaces the global assistant system prompt for that profile's turns.                |
| **Response length** | `Inherit global` (default), `Short`, `Medium`, or `Long`.                                                                           |
| **Greeting**        | An optional opening line shown when the chat is empty.                                                                              |

There is no per-profile voice setting.

<AccordionGroup>
  <Accordion title="How response length interacts with your global setting">
    A profile set to **Inherit global** follows your main response-length preference on the **Assistant** page. Anything else wins for that profile's turns, so a "Quick" persona stays short while an in-depth one runs long.
  </Accordion>

  <Accordion title="Import and export">
    Export the selected profile to a JSON file and import it on another machine. Useful for sharing a persona or backing one up.
  </Accordion>
</AccordionGroup>

<Note>
  Profiles apply to the assistant only. [Generate with
  Flow](/writing/generate-with-flow) and [AI cleanup](/writing/ai-cleanup)
  ignore them. Both are stateless single-shot passes that use only their own
  prompt, so a paste stays predictable no matter which profile is active.
</Note>
