The model is what turns your voice into text. Every model runs on your machine — they trade accuracy for speed, so pick the one that fits your hardware and languages. Open the catalog from *Settings → Dictation → Change model*.

## Recommended models

These five lead the catalog. They run on SpeakoFlow's current engine (a native ggml/GGUF build), and the sizes below are the exact download.

| Model | Size | Languages | Best for |
| --- | --- | --- | --- |
| **Parakeet Unified EN 0.6B** (default) | 697 MB | English only | Blazingly fast everyday dictation. Streams as you speak. |
| **Nemotron Streaming 3.5** | 716 MB | 28 | Real-time multilingual dictation. Streams as you speak. |
| **Canary 180M Flash** | 208 MB | 4 (English, German, Spanish, French) | Tiny and instant — runs well on any machine. Translates to English. |
| **Cohere Transcribe** | 1.7 GB | 14 | The most accurate of the set, and the slowest. |
| **Whisper Medium** | 793 MB | 99 | The widest language coverage. Translates to English. |

A brand-new install is seeded with **Parakeet Unified EN 0.6B**. If it isn't on disk yet, SpeakoFlow falls back to any other transcription model you have downloaded, so the app is never stranded without a working model.

<Note>
  **Streaming models.** Parakeet Unified and Nemotron Streaming can transcribe as you speak, which is what [live transcription](/dictation/live-transcription) needs. Everything else transcribes in one pass when you stop talking.
</Note>

## Older models

Below the recommended list is a collapsed **Older models** group. These run on the previous engine (ONNX and whisper.cpp via transcribe-rs) rather than the current one. They're still fully supported and were never removed — they're just no longer the first suggestion:

- **Whisper Small / Medium / Turbo / Large** — nearly 100 languages. Small, Medium, and Large translate to English; Turbo does not.
- **Parakeet V2** (English only) and **Parakeet V3** (25 languages — mostly European, plus Russian and Ukrainian).
- **Moonshine Base** and **Moonshine V2 Tiny / Small / Medium** — English only, extremely fast, good with accents. The V2 variants stream.
- **Canary 180M Flash** (English, German, Spanish, French) and **Canary 1B v2** (25 European languages). Both translate to English.
- **Cohere** — large, slower, very accurate across 14 languages.
- **SenseVoice** — Chinese, English, Japanese, Korean, and Cantonese. Very fast.
- **GigaAM v3** — Russian only.
- **Breeze ASR** — tuned for Taiwanese Mandarin with English code-switching.

The group stays folded so a first-timer only sees the recommended few, and it opens automatically as soon as you type in the search box.

## Managing models

The catalog splits into **Downloaded models**, **Available to download**, and **Older models**. Your active model sorts first, then the recommended order.

- **Search by name** to filter the list. Searching also reveals the older models.
- **Filter by language** with the globe dropdown — it lists only models that claim support for the language you pick.
- **Delete** a model to free disk space. You'll get a confirmation, and a stronger one if it's your active model.
- The system tray menu also has a model submenu, so you can switch between downloaded models without opening Settings.

### Downloads that survive a bad connection

Model files are large, and a half-finished download used to mean starting over. It doesn't:

- Progress is written to a `.partial` file next to the model, and every retry resumes from where it stopped using an HTTP `Range` request. If the server ignores the range and sends the whole file again, SpeakoFlow notices and restarts cleanly rather than appending garbage.
- Each source is retried up to four times with exponential backoff. A server error, a timeout, or a dropped connection is treated as worth retrying; a permanent client error like a 404 is not, and moves straight on.
- Cancelling keeps the partial file, so resuming later picks up where you left off.
- Older-engine models ship with a SHA-256 checksum and are verified after download. The current GGUF catalog carries no per-file hashes, so those are not checksum-verified.

<Tip>
  The download UI shows live speed and percentage. If a download looks stuck at 0%, it's usually still negotiating the redirect to Hugging Face's CDN — give it a few seconds before cancelling.
</Tip>
