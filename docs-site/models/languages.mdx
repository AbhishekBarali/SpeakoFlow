Language settings appear on the **Models** page under the **Speech to text** tab, below your current model. They only show up when the active model supports them.

| Setting                  | Default          | What it does                                            |
| ------------------------ | ---------------- | ------------------------------------------------------- |
| **Language**             | `Auto`           | Tells the model which language you are speaking.        |
| **Chinese script**       | `As transcribed` | Writes Chinese in Simplified or Traditional characters. |
| **Translate to English** | Off              | Transcribes another language straight into English.     |

Naming your language instead of leaving it on Auto can improve accuracy, because the model stops spending effort guessing. It helps most on short recordings.

<Note>
  Each row only appears when your current model can use it. If you cannot find
  *Translate to English*, the model you are on cannot translate. **Auto** is
  only offered for a model that can work out the language itself.
</Note>

## Your choice is kept when you switch models

The language you pick is saved as your choice, and switching models never changes it. The picker shows what the current model will actually use for it:

- The language you picked, when the model hears it.
- Otherwise **Auto**, when the model can detect the language.
- Otherwise English, or the first language the model lists if it has no English.

So picking Japanese and then switching to an English-only model shows English, and switching back to Whisper shows Japanese again.

## Which model for which languages

| Language need                                  | Model                                      |
| ---------------------------------------------- | ------------------------------------------ |
| Widest coverage, 99 languages                  | **Whisper Medium**, or Whisper Large       |
| Real-time multilingual, 28 languages           | **Nemotron Streaming 3.5**                 |
| Highest accuracy across 14 languages           | **Cohere Transcribe**                      |
| 13 languages, real-time, needs a strong GPU    | **Voxtral Mini 4B Realtime**               |
| English, German, Spanish, French               | **Canary 180M Flash**                      |
| English only, fastest                          | **Parakeet Unified EN 0.6B** (the default) |
| Chinese, English, Japanese, Korean, Cantonese  | **SenseVoice Small**                       |
| Russian                                        | **GigaAM v3**                              |
| Taiwanese Mandarin with English code-switching | **Breeze-ASR-25**                          |

Parakeet is English only. Nemotron covers 28 languages with automatic detection. Whisper Medium is the widest at 99.

To find every model for your language, use the language filter on the Speech to text tab. See [Transcription models](/models/transcription-models#searching-and-filtering).

## Which models translate to English

Translation is a separate task from recognition. Only some models support it, and the **Translate** filter on the Speech to text tab lists them.

| Model                                                                                                                         | Translates to English |
| ----------------------------------------------------------------------------------------------------------------------------- | --------------------- |
| Whisper Tiny, Base, Small, Medium, Large, Large v2, Large v3                                                                  | Yes                   |
| Whisper Large v3 Turbo, and the English-only Whisper models such as Whisper Small (English)                                   | No                    |
| Canary 180M Flash, Canary 1B Flash, Canary 1B, Canary 1B v2                                                                   | Yes                   |
| Granite Speech 4.0 1B, Granite Speech 4.1 2B                                                                                  | Yes                   |
| Voxtral Mini 3B, Voxtral Small 24B                                                                                            | Yes                   |
| Breeze-ASR-25                                                                                                                 | Yes                   |
| Everything else, including Parakeet, Nemotron, Moonshine, Cohere, SenseVoice, GigaAM, Qwen3-ASR, and Voxtral Mini 4B Realtime | No                    |

Whisper Large v3 Turbo catches people out. It is a Whisper model, but it does not support translation.

Leave translation off and you get a transcript in the language you spoke. Turn it on and you get English. If you are already speaking English, the model transcribes as usual.

### Cloud translation

Cloud providers that use the OpenAI multipart format (OpenAI, Groq, and any OpenAI-compatible server you set up yourself) support translation to English through a separate `/audio/translations` endpoint. Other cloud providers do not.

If translation is on but the selected cloud provider does not support it, SpeakoFlow transcribes normally and logs a warning. The setting row in the cloud section says so in place of a switch that would do nothing.

## Simplified and Traditional Chinese

There are two ways to get the script you write in.

**Pick it as the language.** The language list has both Simplified Chinese and Traditional Chinese. The model is told `zh` either way, and SpeakoFlow converts every transcript into the script you picked afterwards, with OpenCC, on your computer.

**Use Chinese script.** With the language on Auto or Cantonese, the **Chinese script** row picks Simplified, Traditional, or As transcribed (the default, which leaves the text as the model wrote it). It converts Chinese only. On Auto, a dictation that comes out in English or Japanese is left alone, so you can switch languages freely and only your Chinese is converted. Traditional Cantonese follows Hong Kong's character conventions, Traditional Mandarin Taiwan's.

The row only appears where it can change something: for a model that can write Chinese, and in the cloud transcription settings, since every cloud provider can answer in Chinese. It is hidden while Simplified or Traditional Chinese is picked as the language, because that choice already decides the script.

<AccordionGroup>
<Accordion title="Language as a hint for cloud providers">
  The language setting is forwarded to cloud providers as a recognition hint:
  `language_code` on ElevenLabs, `language` on the OpenAI schema and Deepgram.
  The transcript still comes back in the language spoken. Script subtags like
  `zh-Hans` and `zh-Hant` are stripped on the way out, because no cloud endpoint
  here understands them. The Simplified or Traditional conversion still happens
  on your computer.
</Accordion>

  <Accordion title="Custom words work differently per model">
    Whisper models receive your custom words as a recognition prompt, and models that accept a vocabulary receive them as vocabulary. Both bias the model before it decides. Every other model gets a fuzzy correction pass over the finished transcript instead.

    Both work. Biasing the model tends to be more accurate because nothing has to be guessed after the fact. See [Custom words](/dictation/custom-words).

  </Accordion>
</AccordionGroup>
