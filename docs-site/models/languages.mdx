Language settings appear on the **Models** page under the **Speech to text** tab, below your current model. They only show up when the active model supports them.

| Setting                  | Default | What it does                                        |
| ------------------------ | ------- | --------------------------------------------------- |
| **Language**             | `Auto`  | Tells the model which language you are speaking.    |
| **Translate to English** | Off     | Transcribes another language straight into English. |

Naming your language instead of leaving it on Auto can improve accuracy, because the model stops spending effort guessing. It helps most on short recordings.

<Note>
  Both rows only appear when your current model supports them. If you cannot
  find *Translate to English*, the model you are on cannot translate. The whole
  group is hidden for models with nothing to configure.
</Note>

## Which model for which languages

| Language need                                  | Model                                      |
| ---------------------------------------------- | ------------------------------------------ |
| Widest coverage, 99 languages                  | **Whisper Medium**, or Whisper Large       |
| Real-time multilingual, 28 languages           | **Nemotron Streaming 3.5**                 |
| Highest accuracy across 14 languages           | **Cohere Transcribe**                      |
| 13 languages, real-time, needs a strong GPU    | **Voxtral Mini 4B Realtime**               |
| English, German, Spanish, French               | **Canary 180M Flash**                      |
| English only, fastest                          | **Parakeet Unified EN 0.6B** (the default) |
| Chinese, English, Japanese, Korean, Cantonese  | **SenseVoice**                             |
| Russian                                        | **GigaAM v3**                              |
| Taiwanese Mandarin with English code-switching | **Breeze ASR**                             |

Parakeet is English only. Nemotron covers 28 languages with automatic detection. Whisper Medium is the widest at 99.

## Which models translate to English

Translation is a separate task from recognition. Only some models support it.

| Model                                                                                                        | Translates to English |
| ------------------------------------------------------------------------------------------------------------ | --------------------- |
| Whisper Small, Medium, Large                                                                                 | Yes                   |
| Whisper Turbo                                                                                                | No                    |
| Canary 180M Flash, Canary 1B v2                                                                              | Yes                   |
| Everything else (Parakeet, Nemotron, Moonshine, Cohere, SenseVoice, GigaAM, Voxtral, Granite Speech, Breeze) | No                    |

Whisper Turbo catches people out. It is a Whisper model, but it does not support translation.

Leave translation off and you get a transcript in the language you spoke. Turn it on and you get English.

### Cloud translation

Cloud providers that use the OpenAI multipart format (OpenAI, Groq, and any OpenAI-compatible server you set up yourself) support translation to English through a separate `/audio/translations` endpoint. Other cloud providers do not.

If translation is on but the selected cloud provider does not support it, SpeakoFlow transcribes normally and logs a warning. The setting row in the cloud section says so in place of a switch that would do nothing.

## Simplified and Traditional Chinese

The language list includes both Simplified Chinese and Traditional Chinese. Both are sent to the model as `zh`, so the model does not distinguish between them.

The distinction matters after transcription. When you select Simplified Chinese, SpeakoFlow converts the output from Traditional to Simplified using OpenCC. When you select Traditional Chinese, it converts the other way. This happens locally, after the model has finished.

<AccordionGroup>
  <Accordion title="Your language choice is only a hint">
    The language you pick is passed to the model only if that model claims to support it. If it does not, SpeakoFlow falls back to autodetection rather than forcing a language the model cannot handle.

    Picking Japanese while an English-only model is active changes nothing.

  </Accordion>

<Accordion title="Language as a hint for cloud providers">
  The language setting is forwarded to cloud providers as a recognition hint:
  `language_code` on ElevenLabs, `language` on the OpenAI schema and Deepgram.
  The transcript still comes back in the language spoken. Script subtags like
  `zh-Hans` and `zh-Hant` are stripped on the way out, because no cloud endpoint
  here understands them.
</Accordion>

  <Accordion title="Custom words work differently per model family">
    Whisper-family models receive your custom words as a recognition prompt, which biases the model before it decides. Every other family gets a fuzzy correction pass over the finished transcript instead.

    Both work. The Whisper route tends to be more accurate because nothing has to be guessed after the fact. See [Custom words](/dictation/custom-words).

  </Accordion>
</AccordionGroup>
