SpeakoFlow is a free, open-source desktop voice assistant for Windows, macOS, and Linux. Talk and it types, in any app. Ask and it answers. Start a conversation and talk it through. It also writes up your meetings.

Speech is transcribed on your own computer by default. The assistant uses whichever model you choose: the built-in offline engine, your own local server, or a cloud provider with your own API key.

The project is on [GitHub](https://github.com/AbhishekBarali/SpeakoFlow).

## Updates and signing

SpeakoFlow checks for new versions in the background (on by default; toggle in _Settings → About_). When an update is available, it shows in the sidebar and in _Settings → About_, where you can install or download it.

Every update is verified against the project's own minisign signing key (public half in the Tauri config, key id `73D1FDFF87780381`). A tampered update will not install.

The installers themselves are not code-signed with an Apple or Microsoft certificate yet. On macOS that means one Terminal command on first install (see [Install](/start/install)). On Windows, SmartScreen may warn the first time you run the installer. The release pipeline is wired for signing and needs only the paid certificates.

The AUR package on Arch Linux updates through your package manager instead of the built-in updater.

## Sending feedback

Click the **?** beside the gear in the sidebar, or go to _Settings → About → Send feedback_, or use **Send feedback** in the tray menu.

The dialog sends exactly what it shows you:

- Your message.
- Your email, only if you type one.
- Up to three screenshots (pasted or picked, shrunk to about 100-400 KB each).
- A system info line, only if you tick the box.

No logs, no transcripts. The report goes to a Cloudflare Worker that files a GitHub issue. The draft is saved as you type, so closing the dialog or a failed send loses nothing.

## Reporting issues and contributing

For bugs not covered in [Troubleshooting](/reference/troubleshooting), [open an issue](https://github.com/AbhishekBarali/SpeakoFlow/issues). Raise your log level to Debug or Trace first (see [Debug & advanced](/settings/debug)) and attach the log file.

Contributions are welcome. [`CONTRIBUTING.md`](https://github.com/AbhishekBarali/SpeakoFlow/blob/main/CONTRIBUTING.md) explains how to get started, and [`CONTRIBUTING_TRANSLATIONS.md`](https://github.com/AbhishekBarali/SpeakoFlow/blob/main/CONTRIBUTING_TRANSLATIONS.md) covers translating the app.
