# Product

## Register

product

## Users and purpose

SpeakoFlow is a desktop voice assistant for dictation, spoken conversation, and optional screen context. It supports local models and user-selected cloud providers. The assistant panel lets users talk while working in other applications.

## Product principles

- Preserve the existing compact panel, profiles, transcript, and provider choices.
- Make microphone activity visible and give users immediate mute and end controls.
- Reduce repeated actions and waiting during a spoken conversation.
- Show listening, processing, and audible playback as distinct states.
- Keep error recovery readable and retain the conversation when voice mode ends.

## Identity and accessibility

Use the committed assistant panel theme and Inter typography. Controls must have translated names, keyboard access, clear focus, sufficient text contrast, and reduced-motion support. Avoid decorative changes to this working desktop surface.
